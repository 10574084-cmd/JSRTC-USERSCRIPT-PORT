# Changelog

## 1.2.0 - 2026-11-08

- Added PAGE GROW to temporarily expand selected page blocks vertically.
- Changed GAME GLITCH to avoid rotating or skewing the canvas, preventing whole-game stretching.
- Updated documentation for the new page-growth mode and canvas behavior.

## JS Lab 1.0.1 - 2026-11-08

- Added a separate JavaScript Lab userscript for user-owned test snippets.
- Added line mixing and numeric-literal mutation controls.
- Runs snippets in a sandboxed worker with blocked network access and a short execution limit.
- Clarified that the lab does not patch live website scripts.

## 1.1.0 - 2026-11-08

- Added IMAGE GLITCH for image and SVG image elements.
- Added VIDEO GLITCH for HTML5 video elements.
- Added GAME GLITCH for canvas-based game render surfaces.
- Added ALL / CHAOS to run every supported visual mode.
- Increased the saved-element limit and documented the visual-only behavior.
- Added compatibility notes for media and canvas rendering.

## 1.0.0 - 2026-11-08

- First public userscript version.
- Added RANDOM CSS-class mixing mode.
- Added web-based TILT rotation mode.
- Added adjustable intensity and delay.
- Added automatic and manual corruption controls.
- Added draggable Shadow DOM control panel.
- Added restore, minimize, and close controls.
- Added installation and limitations documentation.
